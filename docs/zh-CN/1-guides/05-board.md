# board —— 用现成组件组一个仪表盘

> 读者:想要一个仪表盘的用户,和替他干活的 AI。两者读同一份。

## 目标

用户说「我想每天看看美股、比特币和天气」时,**不要新建工具**:Numable 商店里的官方工具已经有这些组件。你要做的是从组件目录里挑组件、填好参数,得到一个**建盘链接**。用户在手机上点开(或扫码)→ Numable 先给出预览 → 用户同意 → 装好工具、建好仪表盘。

只有目录里确实没有用户要的东西,才去新建工具(`numable docs workflow`)。

## 前置

- 有 `numable` 命令时用它校验与出码;没有(例如你在聊天窗口里)也能直接写链接,规则见下文。
- 组件目录:`numable catalog`(一行一个组件),或直接读 `https://api.numable.app/catalog/widgets?format=compact`(JSON;中国大陆加请求头 `x-region: cn`)。精简形态里,同一工具多个组件共用的参数说明只在 `tools[工具].params` 写一次:**先看组件自己的 `ai.params[键]`(`null` = 这个参数没有说明),没有再看工具上的**。不带 `format` 是全量形态,每个组件各写一份。目录只含官方工具,按地区不同。

## 步骤 1 · 查目录

```
numable catalog --grep 天气
```

每行是 `工具.组件 [尺寸] 名称 — 副标题 · 显示 … · 参数 键=默认〔填法〕`。挑组件时看「显示」;要填参数时看〔填法〕。

## 步骤 2 · 写组件清单

每个组件写成 `工具.组件`,要设参数就在后面加 `(键=值,键=值)`:

```
weather.now
stock.quote(secid=105.NVDA)
crypto.coin(pair=ETH-USDT,name=ETH)
```

参数怎么填,只看目录里的〔填法〕:

| 填法 | 意思 | 你怎么做 |
|---|---|---|
| `enum` | 只有几个取值 | 从列出的值里选 |
| `auto` | 默认值能用 | **不确定就别填**;要填按格式写 |
| `value` | 要一个具体的值 | 按格式写,不确定就用默认 |
| 用户自己的数据 | 打卡项、记录的人 | **不填**,装上后用户自己选 |
| 账号里的资源 | App、站点、Zone | **不填** |

- 说明里写着「与 … 一起填」的几个参数,要么全给,要么都不给(例如城市名与经纬度、币对与币名)。
- 用户只说「帮我盯着」没给代码时,优先用默认值;给了具体标的再填参数。
- 最多 8 个组件。

## 步骤 3 · 出码

```
numable board weather.now 'stock.quote(secid=105.NVDA)' hacker.top1 --name 我的早报
```

带括号的组件在 shell 里要加引号。命令会先用线上目录逐项校验,**任何一项不过就不出码**,并说明是哪一项、为什么;都过了输出三样:

- 终端里的二维码 —— 用户用手机系统相机或 Numable 里的扫一扫扫它;
- 分享链接 `https://get.numable.app/b#…` —— 发到手机上点开也行;
- `numable://app/board?…` —— 在装了 Numable 的电脑上直接打开(加 `--open` 自动打开)。

不是终端时不画二维码,加 `--svg board.svg` 输出图片;`--json` 给程序用。

## 没有 numable 命令时:直接写链接

```
https://get.numable.app/b#n=我的早报&i=weather.now,stock.quote(secid=105.NVDA),hacker.top1
```

- `n` 是仪表盘名(可省,最多 12 字),`i` 是组件清单,逗号分隔。
- 参数值里要出现 `,` `(` `)` `&` `#` `=` `%` 时写成 `%2C` `%28` `%29` `%26` `%23` `%3D` `%25`;中文等其余字符原样写。
- 链接在电脑浏览器里打开会显示预览和二维码;在手机上点开,装了 Numable 就直接进预览。
- 参数只在 `#` 后面,不会发送到服务器。

## 规则

- **只能加**:链接只会新建一个仪表盘或往当前仪表盘里加组件,不会删除或修改用户已有的东西。
- **永远先预览**:App 打开链接后先给用户看要装哪些工具、加哪些组件,用户同意了才安装。
- 校验不过的组件会在预览里列出原因、不会加进去;其余照常。
- 需要绑定账号的组件(如 GitHub、Cloudflare)可以选,装上后用户要自己绑定。

## 例子

```
numable board 'stock.quote(secid=105.NVDA)' 'crypto.coin(pair=BTC-USDT,name=BTC)' stock.usmarket --name 我的持仓
numable board weather.now 'forex.rate21(base=USD,quote=CNY)' calendar.month --name 早上看一眼
numable board hacker.top1 github.inbox ccusage.today --name 开发者
```

## 出了问题

| 提示 | 原因 | 怎么改 |
|---|---|---|
| 当前地区的官方工具里没有这个组件 | 组件名写错,或这个工具不在用户所在地区 | `numable catalog` 查准确的 `工具.组件` |
| 参数 … 不能由链接设置 | 这个参数指向用户自己的数据或账号 | 去掉它,装上后用户自己选 |
| 还要一起填 … | 成组的参数只给了一部分 | 补全,或整组都不填 |
| 参数 … 的值不在可选范围里 | 枚举值写错 | 照〔填法〕里列出的值写 |
| 写法不对 | 不是 `工具.组件(键=值)` | 检查括号与等号 |
